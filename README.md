\## Key Finding



> Pornography use is linked to lower productivity — but only because it erodes self-control. The effect applies to both genders, and early exposure may make it worse.



\---



\## Study Overview



This study investigated four questions:



1\. Is pornography consumption correlated with productivity?

2\. Does self-control mediate this relationship?

3\. Does age of first exposure matter for adult outcomes?

4\. Are there gender differences in consumption and outcomes?



\---



\## Key Results



| Objective | Finding | Statistic |

| :--- | :--- | :--- |

| 1. Correlation | Weak negative relationship | rs = -0.157, p = 0.013 |

| 2. Mediation | Full mediation through self-control | Indirect beta = -0.188, 95% CI \[-0.287, -0.098] |

| 3. Age of exposure | Earlier exposure predicts lower outcomes | F = 4.12, p = 0.003 |

| 4. Gender | Males consume more; outcomes similar | p < 0.001 (consumption); n.s. (outcomes) |
